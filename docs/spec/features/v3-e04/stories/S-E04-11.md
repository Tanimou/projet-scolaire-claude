### 3.4 Neutralise formula prefixes and bare `\r` (AC-4)

**DECISION, and it must be stated in a comment:** for a cell whose **first character** is one of
`=` `+` `-` `@` `\t` `\r`, emit it **force-quoted and prefixed with a single apostrophe** (`'`) — the OWASP
CSV-injection form. Additionally, add `\r` to the quote-trigger set so a bare carriage return can never split a
record.

```ts
/** Leading characters that make Excel/LibreOffice treat a cell as a FORMULA. */
const FORMULA_LEAD = /^[=+\-@\t\r]/;

function csvEscape(v: unknown): string {
  if (v == null) return '';
  const s = String(v);
  // CSV injection. The file carries a UTF-8 BOM (see the return of
  // generateAuditCsv), so French Excel opens it AS A SPREADSHEET — a cell
  // beginning `=` is then executed, not displayed. No exported column is
  // reachable free text today; `audit_log.user_agent` is a raw client header one
  // column away and S-E04-3 has started populating it, so this is fixed BEFORE a
  // slice widens the export, not after.
  //
  // CHOICE: prefix with a single apostrophe and force-quote (OWASP). It is
  // ADDITIVE — nothing is dropped from a regulator's file, and the original
  // value is recovered by stripping exactly one leading `'` from an affected
  // cell. Force-quoting alone does NOT protect: Excel formula-parses `"=1+1"`.
  const injectable = FORMULA_LEAD.test(s);
  const body = injectable ? `'${s}` : s;
  if (injectable || /[",\n\r]/.test(body)) return `"${body.replace(/"/g, '""')}"`;
  return body;
}
```

Non-negotiables for whatever form you land:

- **Nothing is dropped.** Stripping or replacing characters in a regulator's file is not an option.
- **Ordinary values are byte-identical to today.** `Résultats`, `role.delete`, `10.0.0.1`, an ISO timestamp and an
  empty cell must all come out exactly as they do at HEAD. The escaper may only change cells that are dangerous.
- **The comment names the choice and the reason**, and names the recovery rule for a downstream parser.
- A cell may legitimately begin with `-` (an id, a negative-looking token). It gets quoted and prefixed too. Say so
  in the comment: correctness of rendering beats aesthetics on this file.
